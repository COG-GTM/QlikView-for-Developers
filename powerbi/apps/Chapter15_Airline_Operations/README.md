# Chapter 15 – Airline Operations (base model)

Power BI version of `Chapter15/Solution_Chapter 15_Airline Operations.qvw`, the full Airline Operations
model the earlier Airline chapters are derived from. Generated by `powerbi/tools/build_airline_base.py`
(do not edit the TMDL by hand; change the builder and rerun it).

| Qlik | Power BI |
| --- | --- |
| `[Main Data]` = Flight Data.qvd + Concatenate Employment Statistics.QVD | `Main Data` (`Table.Combine`) |
| `[Master Calendar]` (AUTOGENERATE / WHILE / AutoNumber) | `Master Calendar`, one row per month, `PeriodID` / `QuarterID` |
| `WHERE Exists(key)` + `'Unknown'` members | `fnFactKeys` + `Table.SelectRows` / `List.Difference` |
| Metric picker inline table (`INLFED-1`) and `$($(=eMetric))` | `INLFED-1` + `Selected Metric` (SWITCH on SELECTEDVALUE) |
| Section Access (USERID, %FLIGHTTYPE, OMIT) + `INLFED` | roles ADMIN, DF, DU, IF, NOCARRIER on `INLFED[%FLIGHTTYPE]`; OLS on `Carrier Name` |
| Alternate states Group A / Group B | disconnected `Group A` / `Group B` period tables |
| Calculated dimensions (Aggr/Class buckets, deal status) | calculated columns with `annotation ParityKey` |
| 92 chart expressions (48 distinct) | 48 measures with `annotation ParityKey` |

Semantic differences are listed in `model.json` (`semantic_gaps`). Parity: source side in
`powerbi/parity/expected/`, DAX queries (run as role ADMIN) in `powerbi/parity/dax/`.
